# NIT7ER | Premium Restaurant Systems

## Overview
NIT7ER is a premium restaurant system design studio that helps restaurants increase bookings, reduce manual workload, and operate flawlessly using automated systems. This repository contains the source code for the NIT7ER landing page.

## Features
- **Digital Storefront**: High-converting digital storefront and beautiful website.
- **Smart Bookings**: Automated calendar syncing and management for 24/7 reservations.
- **WhatsApp Automation**: Instant WhatsApp replies for FAQs and table confirmations.
- **Retention Engine**: Automated follow-ups, special offers, and birthday messages to bring guests back.

## Technologies Used
- HTML5
- CSS3 (Custom Variables, Flexbox, CSS Grid)
- JavaScript (Lightweight scrolling behavior)
- FontAwesome (Icons)
- Google Fonts (Montserrat, Open Sans)

## Project Structure
- `index.html`: The main HTML file containing the structure of the landing page.
- `style.css`: The stylesheet defining the design, layout, and mobile responsiveness.
- `script.js`: Lightweight JavaScript file for functionality.
- `bg.png`: The background image used on the landing page.

## How to Run Locally
1. Clone the repository to your local machine.
2. Open the `index.html` file in your preferred web browser. No local server is required.
